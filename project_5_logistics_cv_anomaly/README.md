# FleetVision: Real-Time Computer Vision & Edge Anomaly Detection Pipeline (AI/ML)

## High-Impact Resume Bullets
* Built an edge-deployable PyTorch Convolutional Neural Network (CNN) for real-time logistics package defect inspection, operating at 1,749 FPS (0.572 ms/frame) on CUDA.
* Implemented gradient saliency attribution algorithms dynamically pinpointing defect centroid pixel coordinates for explainable computer vision quality control.
* Integrated automated pneumatic reject diverter triggers with high-speed confidence gating and confusion matrix tracking.
* Fully verified via 5-test unit suite (`pytest`) and an end-to-end multi-parcel conveyor belt dry-run simulation.
